## Introducción 📖
Inca Fit es una aplicación web desarrollada como Trabajo de Fin de Grado (TFG) para la Universidad de Salamanca. El sistema permite a los usuarios:

- Registrar y monitorear actividades deportivas
- Visualizar estadísticas de progreso
- Gestionar rutinas de entrenamiento
- Compartir logros con la comunidad universitaria

**Objetivo principal**: Crear una plataforma unificada para el seguimiento deportivo de la comunidad universitaria.

## Características Principales ✨
- ✅ Autenticación de usuarios con Spring Security
- ✅ Registro de actividades deportivas (running, ciclismo, natación)
- ✅ Dashboard con estadísticas personalizadas
- ✅ Sistema de logros y recompensas
- ✅ Perfiles de usuario personalizables
- ✅ Interfaz responsive con Bootstrap
